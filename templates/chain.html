Why this ledger can't be altered

The blocks table in blockchain.db is append-only. Two database triggers (blocks_no_update, blocks_no_delete) make UPDATE and DELETE fail at the database engine level — for every caller, not just this website. On top of that, every block's hash is chained to the one before it (SHA-256), so even a direct edit to the database file would break the chain and show up as invalid below.

Run python attempt_tamper.py from a terminal (with the app stopped) to see the database itself reject an UPDATE and a DELETE attempt.
